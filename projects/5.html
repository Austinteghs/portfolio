U.S. Restaurant Data Analysis

Data Analysis · SQL · Excel · Tableau

SQLExcelTableauData AnalysisData Cleaning50 States

Project Overview

End-to-end analysis of U.S. restaurant data spanning all 50 states — from raw data cleaning through to visual insights on restaurant brand distribution, density, and category trends.

Process

  • Data Cleaning (SQL + Excel): Removed duplicates, standardized state codes, corrected restaurant category names, handled null address fields
  • Analysis (SQL): Queried restaurant counts by state, brand market share per region, category distribution, and density metrics (restaurants per capita)
  • Visualization (Tableau): Built an interactive dashboard with a U.S. choropleth map, top-10 brand rankings, and category breakdowns filterable by state

Key Insights

  • California, Texas, and Florida account for over 30% of total U.S. restaurant locations
  • Fast food chains dominate in Midwest states; casual dining is more prevalent on the coasts
  • Several brands show highly concentrated geographic presence, suggesting franchise strategy differences

Skills Demonstrated

Multi-step analytical workflow, cross-tool data pipeline (raw data → SQL → Excel → Tableau), and the ability to surface actionable business insights from geographic and categorical data.
