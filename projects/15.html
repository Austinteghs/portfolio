QA Testing a Student Results Calculator

QA Testing · Test Case Design · Manual Testing

Manual TestingTest Case DesignBug TrackingPythonInput ValidationQA Fundamentals

Project Overview

A manual QA testing project targeting a simulated Python-based student results calculator application — designed to validate score computation, grade assignment, and edge case handling.

Testing Methodology

  • Test Case Design: Wrote structured test cases covering expected inputs, boundary values, and invalid inputs
  • Boundary Value Analysis: Tested score boundaries (0, 40, 49, 50, 69, 70, 100) to verify correct grade assignment
  • Input Validation Testing: Tested negative scores, scores over 100, empty inputs, and string inputs
  • Bug Tracking: Documented all defects found with severity, steps to reproduce, and expected vs actual results

Bugs Identified

  • Incorrect grade boundary — a score of 70 was assigned a B instead of an A due to an off-by-one error
  • No handling for negative score inputs — the app computed and displayed negative grades
  • Empty input caused an unhandled exception crash rather than a friendly validation message

Skills Applied

This project demonstrates analytical thinking, attention to detail, and the ability to systematically uncover logic errors in software — core skills that transfer directly to data quality testing and pipeline validation.
