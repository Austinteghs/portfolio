Project Overview

A GitHub repository of SQL queries written across PostgreSQL and Microsoft SQL Server — covering data analysis, data cleaning, and complex analytical transformations.

Query Categories

  • Data Cleaning: Deduplication, null handling, string normalization, date standardization, and type casting scripts
  • Exploratory Analysis: Aggregations, group-bys, distribution analysis, and summary statistics queries
  • Advanced Analytics: Window functions (RANK, ROW_NUMBER, LAG/LEAD), recursive CTEs, and multi-table JOINs
  • Data Quality Checks: Validation queries that surface orphaned records, out-of-range values, and referential integrity violations

Tools

Queries were written and tested in both pgAdmin (PostgreSQL) and Microsoft SQL Server Management Studio (SSMS), demonstrating comfort across the two most common enterprise SQL engines.

Value

Strong SQL is the foundation of both data engineering (transformations, pipeline logic) and analytics engineering (dbt models, semantic layer definitions). This repository reflects that depth.
