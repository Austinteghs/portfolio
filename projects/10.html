Project Overview

A collection of Python data science and machine learning projects hosted on GitHub, covering the full analytical workflow from raw data to predictive models.

Projects Included

  • Heart Disease Classification: Binary classification model to predict heart disease presence from clinical features using logistic regression and random forest, with ROC-AUC evaluation
  • BMI & Health Status Prediction: Regression model predicting BMI from lifestyle and biometric inputs, with feature importance analysis
  • Telecom Churn Analysis: EDA and predictive modelling to identify customers likely to churn, enabling targeted retention strategies
  • Exploratory Data Analysis (EDA): Multiple EDA notebooks demonstrating data profiling, distribution analysis, correlation matrices, and outlier detection

Technical Approach

All projects follow a consistent structure: data loading → cleaning → EDA → feature engineering → modelling → evaluation. Visualizations use matplotlib and seaborn; models use scikit-learn.

Value

These projects demonstrate the analytical foundation that underpins good data engineering — understanding the data deeply before building pipelines to move and transform it.
