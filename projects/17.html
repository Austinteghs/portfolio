QA Testing the Pay4Energy AEDC Portal

QA Testing · Bug Reporting · UX Analysis

QA TestingBug ReportingUX AnalysisUser Journey TestingTechnical DocumentationProblem Solving

Project Overview

A systematic QA investigation of the Pay4Energy AEDC (Abuja Electricity Distribution Company) portal — identifying critical bugs affecting real users trying to pay electricity bills and top up meters.

Testing Approach

  • User Journey Testing: Mapped and walked through all primary user flows — registration, login, payment, and meter top-up
  • Environment Testing: Tested across multiple browsers and device types to isolate platform-specific bugs
  • Cache & Session Testing: Identified issues with stale cache causing incorrect account states and phantom errors
  • Payment Flow Analysis: Documented payment timeout failures and the absence of graceful error handling

Key Bugs Found

  • Cache errors displaying outdated meter balances after top-up
  • Payment timeouts with no user feedback or retry mechanism — leaving users uncertain whether payment was processed
  • Form validation gaps allowing invalid meter numbers to pass initial checks
  • Session management issues causing users to be logged out mid-transaction

Deliverables

A structured bug report with severity classifications, reproduction steps, screenshots, and recommended fixes — formatted for a development team to action directly.

Impact

Documented issues that were directly affecting bill payment success rates for AEDC customers. Recommended solutions addressed both immediate fixes and longer-term UX improvements.
